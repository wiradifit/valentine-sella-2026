# 💝 Valentine Sella 2026

An interactive web experience built for Valentine's Day 2026 — playful frontend design driven by pure CSS animations and JavaScript micro-interactions. No frameworks, just the platform.

## Highlights

- Handcrafted CSS keyframe animations
- Interactive moments powered by vanilla JS (`script.js`)
- Self-contained assets — zero external dependencies

## Structure

| File | Purpose |
|---|---|
| `index.html` | Entry point |
| `style.css` | Animations & theming |
| `script.js` | Micro-interactions |
| `assets/` | Images & media |

## Run It

Open `index.html` in any modern browser — no build step needed.
